# Contributing to OttoBudget

Thank you for your interest in contributing to **OttoBudget**!

## How to Contribute
1. Fork the repository and create your feature branch (`git checkout -b feature/amazing-improvement`).
2. Open the project in **Android Studio** (Ladybug / Meerkat or newer) with JDK 17.
3. Keep all UI components strictly aligned with the minimalist monochrome icon system, iOS-inspired glassmorphic navigation dock, and `#6BD0C2` Otto Turquoise accent palette.
4. Commit your changes (`git commit -m 'Add new magic words or feature'`) and open a Pull Request.
